# Ashwood: The Lost Lantern

A small playable 2D RPG demo built from scratch in Godot 4.3.

Controls: WASD/Arrow Keys to move, E to interact, Space to attack.

Demo loop: talk to Elder Rowan, defeat the slime, return to Rowan, finish the demo.

All visuals are drawn at runtime, so the project has no external art dependencies.

Windows export is configured through GitHub Actions.
